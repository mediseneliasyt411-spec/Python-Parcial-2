# Examen parcial 2 — Fundamentos de Python

**Proyecto de práctica y documentación** basado en los temas visibles en el material “Examen parcial 2”.

## Objetivo
Reforzar los fundamentos de Python mediante ejemplos ejecutables, explicación de cada tema y una práctica integradora de calificaciones.

## Estructura
- `01_tipos_y_variables.py`: variables y tipos de datos.
- `02_operadores_aritmeticos.py`: operaciones matemáticas.
- `03_operadores_comparacion_logicos.py`: comparaciones y `and`, `or`, `not`.
- `04_entrada_de_datos.py`: captura con `input()`.
- `05_conversion_de_tipos.py`: `int()`, `float()`, `str()` y `round()`.
- `06_condicionales.py`: `if`, `elif`, `else`.
- `07_ciclos.py`: ciclos `for` y `while`.
- `08_listas_y_operaciones.py`: listas, índices, métodos, cortes y funciones.
- `09_tuplas.py`: tuplas y desempaquetado.
- `10_conjuntos.py`: conjuntos y operaciones básicas.
- `11_diccionarios.py`: pares clave-valor.
- `12_break_continue.py`: control de ciclos.
- `13_calculadora_calificaciones.py`: práctica integradora solicitada al final del material

## Estructura de documentación de los ejemplos
Cada archivo contiene:
1. **Objetivo** del tema.
2. **Explicación** breve.
3. **Código comentado**.
4. **Resultado esperado** o indicación de lo que se muestra.

## Práctica final: calculadora de calificaciones
El programa solicita el nombre del estudiante y tres calificaciones, las convierte a `float`, las guarda en una colección, calcula el promedio y muestra si aprobó (promedio mayor o igual a 6.0) o reprobó.
